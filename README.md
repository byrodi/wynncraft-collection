# Wynncraft Collection

Personal collection tracker for [Wynncraft](https://wynncraft.com) (Minecraft MMORPG) — owned gear and full-green mythics.

Live gallery: **https://stependiant.github.io/wynncraft-collection/**

## Contents

- **[`all-sets-collection.md`](all-sets-collection.md)** — checklist of every set item in the game (65 sets, 222 items), sorted by set level. Tracks ownership and which pieces are obtained at green overall (≥80% roll).
- **[`full-green-mythics/`](full-green-mythics/)** — screenshots of owned mythics in *full green* (every identified stat rolled ≥80%). One `<name>.png` per item.

## Terminology

- **Overall roll** — weighted quality of an item's identifications. **Green** = ≥80%, **blue** = ≥95% (the most valuable / collectible rolls).
- **Full green** — every individual stat on the item rolled ≥80%, not just the overall.

Data sourced from the [Wynncraft API v3](https://api.wynncraft.com/v3/) and verified in-game.
