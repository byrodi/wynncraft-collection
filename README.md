# Wynncraft Collection

Personal Wynncraft collection with a gallery of full-green mythics and a checklist of every set item.

[Open the gallery](https://byrodi.github.io/wynncraft-collection/)

## What is inside

- A gallery of owned mythics, one in-game tooltip per item
- Search by item name and a 2x tooltip viewer on the site
- A [checklist](all-sets-collection.md) of all 222 set items in 65 sets, with ownership and green rolls

## Terms

| Term | Meaning |
| --- | --- |
| Overall roll | Weighted quality of an item's identifications |
| Green | Overall roll of 80% or more |
| Blue | Overall roll of 95% or more, the most collectible |
| Full green | Every identified stat rolled 80% or more, not only the overall |

## Adding an item

Put a tooltip screenshot into `full-green-mythics/` and push. GitHub Pages rebuilds the gallery, and the file name becomes the item name, with underscores shown as spaces. [wynnhermes](https://github.com/byrodi/wynnhermes) reads the same folder to skip mythics that are already owned.

Set data comes from the [Wynncraft API v3](https://api.wynncraft.com/v3/) and was checked in game.
