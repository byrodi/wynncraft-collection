# Security Policy

## Supported versions

The project has no releases. Security fixes go into the latest commit on `main` and the site rebuilds from it.

## Reporting a vulnerability

Do not open a public issue. Report privately through GitHub:
https://github.com/byrodi/wynncraft-collection/security/advisories/new

This covers the gallery site, for example a file name or search input that injects script into the page. Include the steps to reproduce and the impact you expect. Reports are acknowledged within 7 days. A confirmed vulnerability is fixed on `main` and disclosed through a GitHub Security Advisory, normally within 90 days of the report.
